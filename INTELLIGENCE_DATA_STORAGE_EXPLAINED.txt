========================================
HOW TO VIEW THE DATA
========================================

OPTION 1: In the Desktop App (Recommended)

After integration, you'll see:

1. Edit a lead → Click "Enhanced Scrape"
   • Runs all 5 intelligence sources
   • Stores everything in the lead
   • Updates signal score

2. Click "View Intelligence" button
   • Opens tabbed viewer
   • Shows: Overview, News, Permits, LinkedIn, etc.
   • Easy to read format

OPTION 2: Directly in JSON File

Open: LeadGENApp/data/leads.json

Find your lead and look at the "intelligence" section.
All data is stored there in JSON format.

OPTION 3: Command Line (Testing)

Run unified scoring directly:

  python unified_signal_scoring.py "Company Name" "website" "email"

This shows all results in the terminal.

========================================
WHAT EACH BUTTON DOES
========================================

After integration, the edit lead dialog will have:

[💾 Save]
  • Saves changes to lead
  • Does NOT run enrichment

[🔍 Basic Scrape]
  • Quick scrape (2-3 seconds)
  • Only checks website for emails/phones
  • Single page only
  • Use when you just need contact info fast

[🎯 Enhanced Scrape] ← USE THIS FOR FULL INTELLIGENCE
  • Complete analysis (20-35 seconds)
  • Checks: Website (10 pages), News, Permits, LinkedIn, Email
  • Stores ALL data in lead.intelligence
  • Updates signal score with comprehensive data
  • Shows summary popup with results

[📊 View Intelligence]
  • Opens intelligence viewer window
  • Tabbed interface showing all collected data
  • News articles, permits, LinkedIn, etc.
  • Only works if you've run Enhanced Scrape first

[❌ Cancel]
  • Closes dialog without saving
